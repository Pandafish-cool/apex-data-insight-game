# APEX Data Insight · 你真的了解用户吗？

一个 6 分钟的网页小游戏，用来和大家聊聊：为什么我们要研究用户行为，以及怎样把它放进每天的思考里。

**在线试玩：** https://pandafish-cool.github.io/apex-data-insight-game/

## 4 个关卡
1. **用户体验常识**：8 道生活题（餐厅剩菜、外卖成功率、导出按钮背后的真需求、健身房留存……），每题都有“原来如此”的解释。
2. **找到卡点**：看一段用户回放，先凭观察猜，再打开行为日志揭晓。
3. **数据侦探**：用线索破案，选出对的设计方案。
4. **需求排序**：先凭“谁说得最大声”选，再看数据改选。

结尾：把用户行为放进每天的思考里（留存、成功率、报错与路径、效率、用户的声音），以及 APEX Data Insight 会员招募。

## 说明
- 单个 HTML 文件，无外部依赖，可离线打开；支持中英文、深浅色。
- 真实数据仅包括 304、16/34、36、187，来自 APEX 审计日志（NII 相关，2026-05-23 至 06-23）；其余均为依据日志模式改编的示意数据。

# APEX Data Insight · Do you really know our users?

A 6-minute web game about why we study user behaviour and how to make it part of everyday thinking. Four levels: UX basics, find the friction, data detective and prioritise. Single offline HTML file, bilingual, light/dark. Only 304, 16/34, 36 and 187 are real figures (APEX audit log, NII-related, 23 May–23 Jun 2026); everything else is illustrative.
